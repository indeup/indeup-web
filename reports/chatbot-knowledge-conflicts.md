# 챗봇 지식 충돌 검사 보고서

검사일: 2026-07-25
검사 대상: policy.ts, products.ts, customFit.ts, chatCatalog.ts, worker/worker.js, support/privacy/terms/brand/custom-fit 페이지
원본 데이터: `data/chatbot/knowledge-conflicts.json`

## 요약

21개 지정 비교 항목 중 실제 페이지 간 수치 충돌(A≠B)은 **발견되지 않았습니다** — 보증기간(3년), 제작기간(7~8영업일), 운영시간 등 핵심 정책 수치는 `policy.ts` 단일 소스에서 파생되어 일관됩니다.

다만 "충돌"은 아니지만 실제 운영에서 위험한 **정보 격차(incomplete) 3건**과 **미검증 확정 답변(requires_confirmation) 4건**을 발견했습니다. 아래는 그 상세입니다.

---

### 1. 제품 색상·멀티탭 구성 — 미검증 확정 답변

항목: 상판 5종/프레임 2종 색상, 컴퓨터책상 멀티탭거치대 개수(1인용 1개/2인용 2개)
페이지 A의 정보: `products.ts`는 "정확한 색상은 네이버 스토어에서 확인"이라며 구체적 색상명을 명시하지 않음
페이지 B의 정보: `worker.js` 시스템 프롬프트는 5종/2종 색상과 멀티탭 개수를 구체적으로 확정해서 답변에 사용
위험성: 네이버 스토어의 실제 옵션이 이 값과 다르면 챗봇이 잘못된 옵션을 확정적으로 안내
사용자 확인 필요 여부: **예**
권장 통일안: 실제 판매 옵션과 일치하는지 확인 후 `policy.ts`에 공식 값으로 등록

### 2. 홈바테이블 기본 높이 — 미검증 확정 답변

항목: 홈바테이블 기본 높이
페이지 A의 정보: 마케팅 문구("서서 사용하는 높은 테이블")
페이지 B의 정보: `customFit.ts` 코드상 기본 출고 높이는 720mm(일반 책상과 동일), 바 높이는 주문 시 직접 지정 필요
위험성: 커스터마이징 없이 주문하면 기대와 다른 데스크 높이로 제작될 수 있음
사용자 확인 필요 여부: **예**
권장 통일안: "기본 720mm, 바 높이는 500~1000mm에서 직접 지정 필요"를 페이지·챗봇 답변에 명시

### 3~5. 배송비(제주·도서산간)/반품비/최대 하중 — 정보 격차 (incomplete)

세 항목 모두 사이트 전체에 구체적 수치가 존재하지 않습니다(페이지 간 충돌이 아니라 어디에도 없음). 현재 챗봇은 이 항목들을 추측하지 않고 `needsHumanSupport=true`로 네이버 톡톡 상담에 연결하고 있어 **당장 위험하지는 않지만**, 실제 수치를 확보하면 답변 품질이 향상됩니다.
사용자 확인 필요 여부: **예** (수치 제공 여부는 운영자 결정)

### 6. jump.gif 이미지 vs 챗봇 안전 답변 — 텍스트·비주얼 불일치

항목: 책상 위에 올라서는 것에 대한 안전 인식
페이지 A의 정보: `products/` 히어로 배경(`jump.gif`)이 사람이 책상 위에 올라선 모습을 담고 있음(alt 텍스트는 수정 완료, 이미지 자체는 미교체)
페이지 B의 정보: 챗봇은 실제 라이브 테스트에서 "권장하지 않음"으로 안전하게 답변함(정상)
위험성: 텍스트는 안전하지만 같은 사이트의 비주얼이 반대 인상을 줌
사용자 확인 필요 여부: **예** (이전 QA 라운드에서도 플래그, 계속 미해결)
권장 통일안: 이미지 교체 여부를 운영자가 결정

### 7. 개인정보/AI 대화 저장 — 정책과 실제 동작 일치, 문구만 보완 권장

충돌 없음. 실측 확인 결과 정책 문구(제2·3·6조)와 실제 코드 동작이 일치합니다. 다만 "마스킹된다"는 표현이 Anthropic 전송분까지 마스킹되는 것으로 오인될 수 있어 문구 명확화를 권장합니다(선택 사항, 필수 아님).

---

## 결론

충돌로 인해 전체 작업을 중단하지 않았습니다. 위 7개 항목은 `requires_confirmation` 상태로 `official-facts.json`에 표시했고, 관련된 챗봇 답변은 확정적 문구 대신 조건부/상담 연결 문구를 유지하도록 검증했습니다. 실제 고객에게는 위 검증 필요 문구가 노출되지 않으며, 이는 운영자가 정책을 확정한 뒤 해결해야 하는 항목입니다(최종 보고서의 "관리자 확인이 필요한 항목" 참조).
